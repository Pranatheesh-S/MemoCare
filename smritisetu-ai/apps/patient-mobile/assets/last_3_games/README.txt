Elderly App Redesign Asset Pack

This ZIP contains the main visual assets needed to recreate the 4 redesigned mobile screens in Figma:
1. Memory Lane
2. Story Recall
3. Market Memory - remember items screen
4. Market Memory - find items screen

Folder guide:
- Shared_UI: reusable buttons and decorative elements
- Memory_Lane: portrait asset + final screen preview
- Story_Recall: isolated illustration assets + final screen preview
- Market_Memory: isolated item icons, market background, and both previews

Suggested Figma rebuild approach:
- Recreate the layout using editable rounded rectangles, text, and shadows.
- Use the provided PNGs only for illustrations/icons/decorative assets.
- Build large headers, instruction bars, cards, and buttons as editable shapes in Figma.
- Use the preview screens as placement references.

Main reusable visual style:
- Soft mint background
- Deep green rounded header/buttons
- Cream content cards
- Large bold text for elderly accessibility
- Soft floral and leaf decorations in corners

Included isolated asset types:
- Navigation icons: back, home, repeat instruction, settings
- Decorative leaves and floral bouquets
- Portrait cutout for Memory Lane
- Story Recall icons: house, leaf branch, yellow flower, butterfly, tree, bench
- Market Memory icons: jaapi, gamosa, pitha, basket, leaf item, flower item
- Village market illustration background for the “Find the items” screen

All assets are PNG files.
